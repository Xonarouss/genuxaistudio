### 2. HARDWARE TARGET & 16GB VRAM OPTIMIZATION STRATEGY
The core inference engine MUST be specifically engineered and tuned for **16GB VRAM GPUs (Primary Target: NVIDIA GeForce RTX 5080 - Blackwell Architecture)**:
1. **Native FP8 / FP4 Quantization:** Utilize Blackwell Tensor Cores via **TensorRT 10.x** and **ONNX Runtime (CUDA Execution Provider)** using `FP8 (E4M3)` and `INT8/FP16` mixed precision so large video models fit comfortably within a strict 14.5 GB VRAM ceiling (leaving 1.5 GB headroom for Windows DWM and the UI).
2. **Dynamic VRAM Offloading & Memory Pool:** Implement a custom C++ `VRAMManager` class using `cudaMallocAsync` and pinned host memory (`cudaMallocHost`). Automatically stream model weights between system RAM (DDR5) and VRAM over PCIe between pipeline stages (Decomposition -> LLM Conditioning -> Diffusion Synthesis -> Upscaling/Interpolation).
3. **Tiled Spatio-Temporal VAE:** Implement tiled VAE encoding/decoding with temporal overlap blending to prevent Out-Of-Memory (OOM) spikes during 1080p/60fps video synthesis.
4. **Zero-Copy Frame Piping:** Decode frames via hardware-accelerated **NVDEC (FFmpeg libavcodec)** directly into CUDA device pointers (`CUdeviceptr`), avoiding costly CPU-to-GPU memory copies.

### 3. SYSTEM ARCHITECTURE & TECH STACK

#### A. Smart Local Model Scanner & Official Source Downloader (`ModelRegistry & AutoFetcher`)
The application must NEVER require the user to manually hunt for model weights or CLI binaries in their browser:
1. **Pre-Flight System & Disk Scanner (`ModelScanner.cpp`):**
   * On startup, automatically scan the local application directory (`%LOCALAPPDATA%/GenuxAI/models`), custom user-defined model paths, and existing local AI caches (such as `~/.cache/huggingface/hub`, ComfyUI model directories, or Ollama/LM Studio GGUF folders) to detect if required models or tools are already installed.
   * Verify existing files using fast header + SHA-256 checksum validation so existing models are symlinked/reused instantly without re-downloading.
2. **Curated Official Manifest (`models_manifest.json`):**
   * Maintain an official registry pointing strictly to verified upstream **GitHub Releases** and official **HuggingFace Repositories** for:
     * **Core Binaries:** `yt-dlp.exe` (official GitHub release) & `ffmpeg-master-latest-win64-gpl` (official GitHub BtbN release).
     * **Segmentation & Tracking:** `SAM 2.1 Large` (Official Meta GitHub release) + `ProPainter` (GitHub release for clean-plate inpainting).
     * **Motion & Expression:** `DWPose` (OpenMMLab/GitHub), `DepthAnything-V2`, and `LivePortrait` (KlingTeam GitHub release).
     * **Identity & Object Vault:** `InstantID`, `PuLID`, and `IP-Adapter-FaceID-PlusV2`.
     * **Local LLM Director:** `Gemma 4` (GGUF `Q4_K_M` / `Q8_0` via official release + `llama.cpp` CUDA backend).
     * **Video Synthesis & Interpolation:** `Wan 2.1 V2V 14B FP8` (16GB VRAM optimized) and `RIFE v4.22` (60fps frame interpolation).
3. **In-App Multi-Threaded Downloader (`ModelDownloader.cpp` + UI Manager):**
   * Built-in C++ async HTTP/HTTPS download manager (`libcurl` / WinHTTP) supporting multi-connection chunked downloads, HTTP Range pause/resume, automatic retry, real-time MB/s speed telemetry, ETA calculation, and automatic TensorRT `.engine` compilation upon completion.
   * Dedicated **"Model Hub & Hardware Readiness"** screen inside the Desktop UI where users see green `"Installed & Verified"` badges for detected models, or a 1-click `"Download Missing Models"` button with granular progress bars.

#### B. Native Core Engine (`/engine-cpp`)
* **Language & Build:** C++20, CMake, Ninja, MSVC (Windows 11 SDK).
* **AI & Inference Runtimes:** TensorRT 10.x, LibTorch / ONNX Runtime (CUDA), and `llama.cpp` (for local Gemma 4 inference).
* **Local Database:** **SQLite3** to store the Character Vault, Object Vault, Installed Model paths, Project States, and the Viral Video Library metadata.
* **IPC Bridge:** High-speed local **WebSocket + Shared Memory** server connecting the C++ engine to the Desktop UI for real-time 60 FPS video previewing and live download/render progress telemetry.

#### C. The "Genjutsu" Local AI Pipeline (5-Stage Recast Engine)
Design `PipelineOrchestrator.cpp` to execute the following stages modularly:
1. **Stage 1: Interactive Segmentation & Clean Plate (`TrackerEngine`)**
   * User clicks any person or object in frame 1; **SAM 2** tracks and masks the target across all frames.
   * **ProPainter** inpaints the masked region to reconstruct a clean background plate.
2. **Stage 2: Motion, Depth & Expression Extraction (`MotionExtractor`)**
   * Extract body/hand/face skeletons via **DWPose**, temporal depth via **DepthAnything-V2**, and micro-expressions/lip-sync via **LivePortrait**.
3. **Stage 3: Gemma 4 Director Agent (`GemmaDirector`)**
   * Run **Gemma 4** locally to analyze scene lighting, camera movement, and user instructions, outputting structured JSON with optimized diffusion prompts and ControlNet conditioning weights.
4. **Stage 4: Persistent Character & Object Vault (`CharacterVault`)**
   * Users upload 1-5 photos of any person, character, or object and save them permanently into the Vault.
   * Extract and serialize facial/structural embeddings (`InstantID` + `PuLID`) into `.gchar` vault records for instant zero-shot recasting across any future video.
5. **Stage 5: Video Synthesis & Harmonization (`SynthesisEngine`)**
   * Combine Clean Plate + Motion/Depth + Character Vault Embeddings + Gemma 4 Conditioning into **Wan 2.1 FP8**, followed by **RIFE** 60 FPS interpolation and automated color/lighting harmonization.

#### D. Desktop Application UI (`/desktop-app`)
* **Framework:** **React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion + Lucide Icons** (packaged for Windows via Tauri v2 / Electron with native C++ bridge).
* **Key Workspace Views:**
  1. **Model Hub & Startup Scanner Drawer:** Shows real-time scan results of local disk paths, existing vs. missing models, official GitHub/HF source links, and interactive download progress bars.
  2. **Viral Video Library & Social URL Importer:** Built-in catalog of trending viral templates + a 1-click **"Paste URL"** bar for YouTube, TikTok (watermark-free), and Instagram Reels with automatic scene-cut detection.
  3. **Interactive Recast Studio (Main Viewport):** Dual/Split video canvas with interactive SAM 2 hover-and-click mask selection, bottom multi-track timeline, and right-hand Inspector with 1-Click Character Vault swapping, Gemma 4 Smart Prompt bar, and a live **RTX 5080 16GB VRAM Telemetry Gauge**.
  4. **Character & Object Vault Manager:** Dedicated gallery to create, tag, preview, and manage saved characters and objects.
